# DP Coin Change Algorithm

The method `DPCoinChange` is located in: `CoinChange.java`

## Method Description
`DPCoinChange(int[] coins, int amount)` returns the minimum number of coins
needed to make the target amount, or `-1` if it's impossible.

## Runtime
O(n * A) where n = number of coin denominations, A = target amount

## How to Run
javac CoinChange.java
java CoinChange
